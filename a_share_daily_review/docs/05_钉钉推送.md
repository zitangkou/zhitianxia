# 钉钉消息推送

将早报/复盘**草稿正文**推到钉钉群，便于手机审阅。  
**不等于**自动发小红书；对外发帖仍须人工。

## 1. 创建机器人

钉钉群 → 群设置 → 智能群助手 → 自定义机器人 → 推荐加签 → 复制 Webhook。

## 2. 配置

`config/settings.yaml`（真实 webhook 勿提交公开仓）：

```yaml
notify:
  enabled: false
  channels:
    - type: dingtalk
      enabled: true
      webhook: "https://oapi.dingtalk.com/robot/send?access_token=..."
      secret: "SECxxx"
      msgtype: "markdown"
      at_all: false
```

## 3. 使用

```bash
python scripts/run_morning.py --notify
python scripts/run_daily.py --no-llm --notify
```

## 4. 实现

| 文件 | 说明 |
|------|------|
| `src/notify/dingtalk.py` | 发送与加签、截断 |
| `src/notify/dispatch.py` | 多 channel 分发 |

## 5. 故障

| 现象 | 处理 |
|------|------|
| 关键词错误 | 安全设置含关键词时正文需包含 |
| 加签失败 | 检查 secret 与系统时间 |
| 无推送 | 是否 `--notify` 或 `enabled: true` |
