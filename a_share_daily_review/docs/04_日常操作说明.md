# 日常操作说明

## 环境

```bash
cd zhitianxia/a_share_daily_review
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

本机建议：`data.skip_heavy_endpoints: false`。

## 命令

```bash
python scripts/run_morning.py
python scripts/run_morning.py --llm
python scripts/run_morning.py --notify

python scripts/run_daily.py
python scripts/run_daily.py --no-llm --notify

python -m src.review_ui.app
# http://127.0.0.1:8787

python scripts/run_scheduler.py
```

## 输出

`output/YYYY-MM-DD/`：`morning_draft_*`、`review_draft_*`、`charts/`。

## 发布流程

脚本出草稿 →（可选钉钉）→ 审核台改稿 → **人工**复制到社媒。系统不自动发帖。

内存紧时少开 LLM；详见 `00_项目总览.md`、`AGENTS.md`。
