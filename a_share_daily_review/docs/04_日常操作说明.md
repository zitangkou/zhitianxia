# 日常操作说明（阶段 2～5）

> 原则：**只生成草稿，人工审核后复制发布，不自动发帖。**

## 依赖

```bash
cd a_share_daily_review
pip install -r requirements.txt
# Ollama 已安装则保证服务在跑：ollama serve
```

## 每日命令

```bash
# 盘前早报草稿（默认不用 LLM，省内存）
python scripts/run_morning.py

# 可选中文润色
python scripts/run_morning.py --llm

# 收盘复盘（拉数 + 惊喜点 + 图 + 可选 LLM）
python scripts/run_daily.py
python scripts/run_daily.py --no-llm   # 强制不走模型

# 本机审核台
python -m src.review_ui.app
# 浏览器打开 http://127.0.0.1:8787

# 长期调度（周一至周五 07:30 早报 / 15:45 复盘）
python scripts/run_scheduler.py
# 立刻试跑
python scripts/run_scheduler.py --once morning
python scripts/run_scheduler.py --once review
```

## 输出位置

`output/YYYY-MM-DD/`

| 文件 | 说明 |
|------|------|
| morning_draft_full.md / brief.md / json | 早报 |
| morning_draft_llm.md | 早报 LLM 版（若 --llm 成功） |
| review_draft.md / json | 复盘审核稿 |
| charts/*.png | 情绪柱状、连板梯队 |

## 发布流程

1. 跑脚本出草稿  
2. 打开审核台 → 勾选/改字 → 勾检查清单 → 复制预览  
3. 人工登录小红书等平台粘贴发布  

## Mac mini 提示

- 早报默认关 LLM；复盘若卡顿加 `--no-llm`  
- 图表在 macOS 一般能正常显示中文；Linux 服务器可能缺字体  
- `config/news_sources.yaml` 可关 `fed_press` 等过吵的源
