## 设计决策备忘

| 决策 | 原因 |
|------|------|
| 不做全自动社媒发帖 | 合规与平台风险、敏感内容需人审 |
| 早报国外源优先 | 差异化与吸引力 |
| 复盘强调反常数字 | 区别于喊单与纯翻译资讯 |
| 钉钉只推草稿 | 便于手机审阅，发布权仍在人 |
| Mac 默认少开 LLM | 16G 内存约束 |
