# A股每日复盘 + 盘前早报 · 项目总览

**仓库**：`git@github.com:zitangkou/zhitianxia.git`（monorepo 子目录 `a_share_daily_review/`）  
**定位**：交易日自动生成「盘前海外早报」与「收盘 A 股复盘」**草稿**，经本机审核后人工发布。  
**不做**：全自动发小红书等公开平台、荐股、收益承诺。

**运行环境**：Mac mini（约 4 核 / 16G）+ Python + 可选 Ollama；可迁更强主机。

---

## 已确认运营约定

| 项 | 约定 |
|----|------|
| 定位 | 公开信息整理 + 盘面反常数字 |
| 更新 | 交易日 **早报 + 复盘都发**；忙时用精简版 |
| 声明 | 每帖短版 + 简介长版 |
| 评论 | 不答个股操作建议 |
| 出错 | 评论区置顶更正 |
| 广告 | 前期不接 |
| 成稿 | 模板保底，Ollama 可选润色 |
| 发布 | 草稿 → 审核台 / 钉钉通知 → **人工**复制发布 |
| 消息 | 可推钉钉群（仅通知，非对外发帖） |

详见：`02_内容与审核规范_v1.md`、`03_账号与合规选项_待你确认.md`。

---

## 能力一览

| 模块 | 说明 |
|------|------|
| 收盘复盘 | AkShare 拉指数/涨停跌停/炸板/连板/龙虎榜/席位 → 惊喜点分析 → 图 + 草稿 |
| 盘前早报 | 白名单 RSS（海外为主）→ 时效过滤 → 打分 → 完整/精简帖模板 |
| 审核台 | 本机 `127.0.0.1:8787`，勾选改稿复制，无平台登录 |
| 钉钉推送 | 自定义机器人 Webhook，推送草稿正文到群 |
| 调度 | 默认 07:30 早报 / 15:45 复盘（周一至周五） |

## 目录结构

```text
a_share_daily_review/
├── config/
│   ├── settings.yaml          # 总配置、LLM、调度、notify
│   └── news_sources.yaml      # 早报 RSS 与打分
├── src/
│   ├── data/                  # 行情拉取与落盘
│   ├── analysis/review.py     # 复盘惊喜点
│   ├── news/                  # 早报流水线
│   ├── content/               # 图表、Ollama、复盘草稿
│   ├── notify/                # 钉钉等消息推送
│   ├── review_ui/app.py       # 审核台
│   └── utils/
├── scripts/
│   ├── run_morning.py
│   ├── run_daily.py
│   └── run_scheduler.py
├── output/YYYY-MM-DD/         # 草稿与图（不入库）
├── data/                      # 行情本地数据（不入库）
└── docs/                      # 本文档集
```

```bash
python scripts/run_morning.py --notify

python scripts/run_daily.py
python scripts/run_daily.py --no-llm --notify

python -m src.review_ui.app
python scripts/run_scheduler.py
```
