# A股每日复盘 + 盘前早报系统 · 项目总览

**定位**：交易日自动生成「盘前海外早报」与「收盘 A 股复盘」草稿，经本机人工审核后复制发布。  
**不做**：全自动多平台发帖、荐股、收益承诺。

**当前环境**：Mac mini（约 4 核 / 16G）+ Python + Ollama；后续可迁更强主机。

---

## 1. 已确认运营约定

| 项 | 约定 |
|----|------|
| 定位 | 公开信息整理 + 盘面反常数字（A1） |
| 更新 | 交易日 **早报 + 复盘都发**；忙时用精简版 |
| 声明 | 每帖短版 + 简介长版 |
| 评论 | 不答个股操作建议 |
| 出错 | 评论区置顶更正 |
| 广告 | 前期不接 |
| 成稿 | 模板保底，Ollama 可选润色 |
| 发布 | 草稿 → 审核台 → 人工复制发布 |

规范原文：`docs/02_内容与审核规范_v1.md`、`docs/03_账号与合规选项_待你确认.md`（已确认）。

## 2. 系统能力

### 收盘复盘
- 数据：指数、涨停/跌停/炸板、连板、龙虎榜、营业部席位等（AkShare 主源，可降载）
- 分析：连板梯队、一字/开板回封、地天感、晋级率、游资席位、题材关键词等「反常点」
- 输出：摘要、可选 LLM 润色、情绪/连板图、`review_draft.*`
- 存储：Parquet + SQLite

### 盘前早报
- 白名单 RSS（海外为主：CNBC、MarketWatch、Fed、科技媒体等）
- 时效窗：昨 15:00 起；去重；按区域/冲击力/时效打分
- 输出：完整版 / 精简版 Markdown + JSON；可选 `--llm` 中文润色
- 国内快讯源默认关闭，待本地 RSS 桥再开

### 审核台
- 本机 `http://127.0.0.1:8787`：早报/复盘编辑、勾选、预览、复制、检查清单  
- 无平台登录、无自动发布

### 调度
- 默认交易日 07:30 早报、15:45 复盘（可配）

## 3. 目录要点

```
a_share_daily_review/
├── config/settings.yaml          # 总配置、调度、LLM
├── config/news_sources.yaml      # 早报 RSS 与打分
├── src/data/                     # 行情拉取与落盘
├── src/analysis/review.py        # 复盘惊喜点引擎
├── src/news/                     # 早报采集过滤打分成稿
├── src/content/                  # 图表、Ollama、复盘草稿
├── src/review_ui/app.py          # 审核台
├── scripts/run_morning.py
├── scripts/run_daily.py
├── scripts/run_scheduler.py
├── output/YYYY-MM-DD/            # 当日全部草稿与图
└── docs/                         # 规范与操作说明
```

## 4. 日常命令

```bash
pip install -r requirements.txt

python scripts/run_morning.py              # 早报草稿
python scripts/run_morning.py --llm        # 早报 + Ollama
python scripts/run_daily.py                # 复盘（含图/草稿）
python scripts/run_daily.py --no-llm       # 复盘不用模型

python -m src.review_ui.app                # 审核台
python scripts/run_scheduler.py            # 定时
```

详见：`docs/04_日常操作说明.md`。

## 5. 技术选型摘要

| 环节 | 方案 |
|------|------|
| 行情 | AkShare（可 skip 重接口） |
| 资讯 | RSS + feedparser；可选 RSSHub / china-finance-rss |
| 成稿 | 规则模板 + 可选 Ollama（Qwen） |
| 审核 | FastAPI 本机页 |
| 发布 | 人工 |

原则：源可核对、国外早报优先、复盘突出反常数据、人审闸门不可关。
