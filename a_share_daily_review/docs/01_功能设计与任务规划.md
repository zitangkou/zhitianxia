# 方案一：轻量级内容优先方案 —— 详细功能设计与任务规划

**项目名称**：A股每日自动复盘系统（轻量版）  
**目标**：每日交易日收盘后，自动拉取中国A股数据 → 本地存储 → 生成结构化复盘报告 → 用本地LLM生成小红书风格文案 + 图表 → 打包输出，便于半自动发布，打造财经账号。同时积累本地数据用于后续分析。

**硬件适配**：RTX 5070 (12GB) + 32GB RAM + 1TB。本方案LLM推荐 Qwen2.5-7B/14B 或 Qwen3-8B/14B（Q4），在Ollama/vLLM下运行流畅。

## 二、详细功能模块设计

### 2.1 数据拉取模块 (`src/data/fetcher.py`)
**职责**：可靠获取当日/历史A股数据。

**核心功能**：
- 判断是否为交易日（使用 `chinese_calendar` + 节假日列表）。
- 拉取主要指数：上证综指、深证成指、创业板指、沪深300、中证500、中证1000 等日线。
- 全市场日线快照（或分批）：代码、名称、开高低收、涨跌幅、成交量、成交额、换手率、市值等。
- 涨停/跌停池、连板高度、炸板统计。
- 板块/概念涨跌幅 Top/Bottom（行业、概念）。
- 北向资金（如接口可用）、两市成交额。
- 备用源：Baostock 拉取指定股票历史。
- 重试机制、超时、简单反爬休眠。
- 输出：结构化 dict / DataFrame。

**接口设计**：
```python
class DataFetcher:
    def is_trading_day(self, date: str) -> bool
    def fetch_indices(self, trade_date: str) -> pd.DataFrame
    def fetch_market_snapshot(self, trade_date: str) -> pd.DataFrame
    def fetch_limit_up_down(self, trade_date: str) -> dict
    def fetch_sector_performance(self, trade_date: str) -> pd.DataFrame
    def fetch_northbound(self, trade_date: str) -> dict  # optional
    def run_daily_fetch(self, trade_date: Optional[str] = None) -> dict
```

### 2.2 数据存储模块 (`src/data/storage.py`)
**职责**：持久化、增量更新、查询。

**核心功能**：
- 日线行情按日期分区存 Parquet（`data/parquet/daily/YYYY/MM/DD.parquet` 或按股票分文件）。
- 指数、板块单独表。
- SQLite 记录：运行日志、复盘摘要、信号结果、配置。
- DuckDB 可选用于快速分析查询。
- 支持按日期范围读取、增量追加（避免重复）。
- 数据校验：缺失值、异常涨跌幅检查。

### 2.3 分析引擎 (`src/analysis/review.py`)
**职责**：生成结构化复盘数据，供LLM和图表使用。

**核心计算**：
- **市场概况**：指数涨跌、两市成交额、上涨/下跌/平盘家数、涨停/跌停数量、平均股价涨跌。
- **情绪指标**：涨停家数、连板高度、炸板率、昨日连板表现。
- **板块轮动**：涨幅/跌幅前10行业/概念，资金流向（如有）。
- **异动扫描**：成交额/量比异常放大、创阶段新高、高换手。
- **简单技术**：主要指数 MA5/10/20 位置、MACD 状态（纯pandas实现）。
- **轻量信号**：基于规则 + 可选 LightGBM 小模型的观察池（动量、相对强度）。初期可纯规则。
- 输出：`ReviewResult` dataclass（JSON可序列化）。

### 2.4 图表生成 (`src/charts/generator.py`)
**职责**：生成小红书友好视觉素材。

**图表清单**（每日3-6张）：
1. 主要指数当日涨跌对比柱状图。
2. 涨跌家数饼图 / 分布。
3. 板块涨幅热力图或水平条形图（Top10）。
4. 涨停板梯队/连板统计。
5. 两市成交额近期趋势（近10/20日）。
6. 可选：自选/观察池个股表现。

输出：PNG（高分辨率，白底或深色主题，带标题、水印“仅供学习”）。

### 2.5 LLM 文案生成 (`src/llm/generator.py`)
**职责**：把结构化数据变成吸引人的小红书笔记。

**策略**：
- 优先调用本地 Ollama（`qwen2.5:7b` 或 `qwen2.5:14b` / `qwen3:8b`）。
- Fallback：模板 + 规则填充（保证无LLM时也能产出）。
- Prompt 设计：角色设定（专业但亲和的财经博主）、输出格式（标题 + 正文分段 + 话题标签 + 免责声明）、长度控制、风格要求（emoji、短句、视觉友好）。
- 支持多版本生成（标题池）。
- 输出：Markdown / 纯文本 + 建议标签。

### 2.6 内容打包与通知 (`src/publisher/packager.py`)
**职责**：
- 创建 `output/YYYY-MM-DD/` 目录。
- 写入：`复盘文案.md`、`结构化数据.json`、`charts/*.png`、`README.txt`（使用说明）。
- 可选通知：本地日志 + 文件变化触发，或简单 webhook。

### 2.7 调度与主入口 (`scripts/run_daily.py` + `src/main.py`)
- 检查交易日 → 拉取 → 存储 → 分析 → 图表 → LLM → 打包。
- 命令行参数：`--date 2026-08-20`、`--force`、`--no-llm`、`--mock`。
- 日志完整记录到 `logs/`。

### 2.8 配置 (`config/settings.yaml` + `src/utils/config.py`)
- 数据源开关、LLM 模型名、输出路径、通知配置、观察池股票列表、图表主题等。

## 五、风险与注意事项
- AKShare 接口可能因源站变化失效 → 做好日志与备用源。
- 小红书自动发布风险高 → 本方案以“半自动打包”为主。
- 本系统所有输出仅供学习研究，不构成任何投资建议。
- 在用户本地5070机器上运行时，再启用完整 Ollama + GPU 加速。
