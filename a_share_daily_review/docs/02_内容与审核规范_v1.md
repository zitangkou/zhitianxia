# 内容与审核规范 v1

> 适用：A 股收盘复盘帖 + 盘前隔夜综合帖  
> 发布方式：**只生成草稿 → 人工审核 → 人工选择发布**（不做全自动发帖）  
> 硬件前提：当前 Mac mini（约 4 核 / 16G 内存）+ 已装本地 LLM；后续可迁 5070 主机  

更新：2026-08-20

---

## 1. 账号定位（建议稿，可改）

**一句话定位**  
用「可核对的公开信息 + 当天盘面里反常的数字」，做交易日盘前/盘后的短讯整理，不荐股、不承诺收益。

**不做**  
- 个股买卖点、目标价、跟庄暗示  
- 无来源「内部消息」「庄家意图」  
- 全自动多平台群发  

**更新节奏（已确认：早报 + 复盘都发）**  
| 类型 | 时间（交易日） | 形式 |
|------|----------------|------|
| 盘前综合 | 07:00–08:30 出草稿，开盘前发 | 海外为主，短帖；忙时精简版 |
| 收盘复盘 | 15:45 后出草稿，当晚发 | 反常点 + 情绪/连板等；忙时精简版 |
| 非交易日 | 默认可停更，或只发重大外盘 | 避免凑数 |

忙时两侧均可改发「精简版」，不改为只发一侧。设备（G1）：模板草稿保底，Ollama 润色可选。

## 2. 合规与发帖边界（建议你拍板的选项）

### 2.1 必须遵守的底线（建议全部采纳）

1. 每条对外结论尽量能对应到**公开来源或当日公开行情数据**。  
2. 文末或固定位置保留免责声明（见下）。  
3. **禁止**：保证收益、稳赚、内幕、代客理财、喊单跟单话术。  
4. **禁止**：系统自动登录并发布到小红书/微博等；发布必须人工确认。  
5. 标题与正文避免绝对化：「必涨」「百分百」「绝无」等。  
6. 涉及政策/监管，只转述公开报道，不自行解读成投资指令。

### 2.2 免责声明（已确认：C1 + C2）

**短版（每帖文末，C1）**  
> 内容来自公开信息与行情数据整理，仅供参考，不构成投资建议。市场有风险，决策请独立判断。

**长版（账号简介，C2）**  
> 本账号整理公开媒体报道与公开市场数据，用于信息汇总与盘面现象记录。不荐股、不提供买卖指令、不承诺任何收益。读者应自行核实来源并独立决策。

### 2.3 发帖前检查清单（审核页要勾选的意识清单）

发布前人工确认：

- [ ] 没有具体「买/卖某某」的指令口吻  
- [ ] 没有收益承诺或暗示稳赚  
- [ ] 重要数字来自草稿里的源或行情字段，没有随手改数  
- [ ] 海外内容未擅自写成「明天 A 股一定如何」  
- [ ] 敏感/未核实传闻已删除  
- [ ] 已附短版免责声明（或账号统一签名）  
- [ ] 今日选择的是「完整版」或「精简版」，不是重复灌水  

### 2.4 账号设置向建议（你自行决定）

| 项 | 建议 |
|----|------|
| 昵称/简介 | 强调「整理/复盘/公开信息」，避免「导师/稳赚/内参」 |
| 商业合作 | 若有广告，按平台要求标注；与正文数据帖分开 |
| 评论区 | 统一回复：「不给个股操作建议，请看免责声明」 |
| 出错 | 发现事实错误：评论区置顶更正或删除重发，不装没看见 |

## 3. 内容原则（四条）

1. **真实可靠**：白名单来源；无链接、无出处的条目默认不进成稿。  
2. **时效**：早报以「昨收盘后～今早」为主；复盘只写当日盘面。  
3. **抓眼**：优先反常数字、极值、冲突、首次、高影响主体（美联储、重要公司、汇率商品等）。  
4. **国外优先（早报）**：排序与篇幅上海外/宏观/科技优于一般国内快讯。

## 4. 帖子模板

### 4.1 盘前综合帖 · 完整版

```text
【盘前速览】MM-DD · 隔夜海外

🌍 隔夜必须知道
1. …
2. …
3. …
（建议 5～8 条，短句，带关键数字）

📊 数字速览
· …

👀 今日观察（可选，0～2 条，语气保守，可整段删除）
· …

⚠️ 公开信息整理，不构成投资建议。
```

### 4.2 盘前综合帖 · 精简版（忙时）

```text
【盘前】MM-DD 隔夜5条
1. …
2. …
3. …
4. …
5. …
⚠️ 不构成投资建议。
```

### 4.3 收盘复盘帖 · 完整版

```text
【收盘复盘】MM-DD

⚡ 今日最反常
· （1 条置顶：连板/晋级率/席位/地天等反常点）

📈 市场与情绪
· 指数要点
· 涨停/跌停/炸板等一句话

🔥 结构与亮点
· 连板梯队 / 一字或回封 / 题材情绪等（有则写）

🦈 席位与龙虎榜（可选，偏硬核）
· …

⚠️ 公开数据整理，不构成投资建议。
```

### 4.4 收盘复盘 · 精简版

```text
【复盘】MM-DD · 今日1个反常 + 情绪一句
· 反常：…
· 情绪：…
⚠️ 不构成投资建议。
```

### 4.5 来源区（默认仅草稿/审核页展示）

对外发布可删减为「参考：某某媒体等公开报道」。  
审核页必须保留：标题、来源名、时间、原链接，便于核对。

## 5. 写作口径

| 场景 | 建议写法 | 避免 |
|------|----------|------|
| 外盘涨跌 | 「纳指收跌 x%，报…」 | 「明晚 A 股必杀」 |
| 映射 A 股 | 「需观察是否传导至…」「仅作信息关联」 | 「联动板上车」 |
| 连板/席位 | 「数据上显示…」「公开龙虎榜记录」 | 「游资已控盘」 |
| 不确定 | 「报道称」「截至发稿」 | 脑补细节 |

本地 LLM 若参与润色：**只允许改写表达，不允许新增数字、来源和结论**。

## 6. 审核与发布流程

```
系统出草稿（md + json）
    → 本机审核页：勾选条目 / 改措辞 / 选完整或精简
    → 勾选检查清单
    → 复制正文（+ 另存图）
    → 人工登录平台发布
```

系统**不**保存平台密码，**不**调用平台发帖接口作为默认能力。

## 7. 当前硬件下的执行约束（Mac mini 4 核 / 16G）

1. **优先规则模板草稿**；LLM 润色作为可选项，避免与其它重任务同时开。  
2. 本地模型建议：已装模型中选 **较小量化版（如 7B 级）** 写短帖；长文、多图以后再上更强机器。  
3. 新闻源数量第一版控制在约 **8～15 个 RSS**，并发要低，防止内存尖峰。  
4. 复盘数据拉取：可继续用现有流水线；重接口能关则关，保证每日能出稿。  
5. 审核页与管道以「轻量、本机」为准，不部署复杂多服务。  
6. 日后迁至 5070 / 32G 主机时：再提高模型规模、图表复杂度与源数量，规范本文可不变。
