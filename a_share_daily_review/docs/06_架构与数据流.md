# 架构与数据流

## 1. 总体架构

```text
                    ┌─────────────────┐
                    │  config/*.yaml  │
                    └────────┬────────┘
           ┌─────────────────┼─────────────────┐
           ▼                 ▼                 ▼
    ┌────────────┐   ┌────────────┐   ┌────────────┐
    │ 早报 news  │   │ 复盘 data  │   │  notify    │
    │ RSS 管道   │   │ + analysis │   │ 钉钉等     │
    └─────┬──────┘   └─────┬──────┘   └──────▲─────┘
          │                │                 │
          ▼                ▼                 │
    morning_draft     review_draft ──────────┘
          │                │
          └───────┬────────┘
                  ▼
         review_ui :8787  / 人工复制发布
```

## 2. 盘前早报

| 步骤 | 文件 | 行为 |
|------|------|------|
| 配置 | `config/news_sources.yaml` | 源列表、时间窗、权重、冲击力词 |
| 拉取 | `src/news/fetch.py` | feedparser + 低并发 requests |
| 过滤 | `src/news/filter.py` | 昨 15:00（上海）起、URL/标题去重 |
| 打分 | `src/news/score.py` | 海外优先 × 关键词 × 时效衰减 |
| 成稿 | `src/news/draft.py` | full/brief Markdown + JSON |
| 编排 | `src/news/pipeline.py` | `run_morning_pipeline` |
| 入口 | `scripts/run_morning.py` | `--llm` / `--notify` |

草稿字段要点：`status=pending_review`，`auto_publish=false`，条目含 `selected`。

## 3. 收盘复盘

| 步骤 | 文件 | 行为 |
|------|------|------|
| 拉取 | `src/data/fetcher.py` | 指数、涨停池、炸板、龙虎榜、席位等 |
| 落盘 | `src/data/storage.py` | Parquet 分区 + SQLite 日志 |
| 分析 | `src/analysis/review.py` | 连板、一字/回封、席位、题材、surprise_points |
| 图 | `src/content/charts.py` | 情绪柱状、连板梯队 PNG |
| 草稿 | `src/content/review_draft.py` | review_draft.json/md |
| LLM | `src/content/llm.py` | Ollama chat，失败回落模板 |
| 入口 | `scripts/run_daily.py` | `--no-llm` / `--notify` / `--force` |

惊喜点设计目标：反常、超预期（高连板、低晋级率、席位大额、题材命中等）。

## 4. 审核台

- `src/review_ui/app.py`：FastAPI  
- 读 `output/{date}/morning_draft.json`、`review_draft.json`  
- 保存回写 JSON 与 md  
- 无平台 Cookie、无发帖 API  

## 5. 消息推送

- `src/notify/dingtalk.py`：text / markdown，支持加签  
- `src/notify/dispatch.py`：读 `settings.notify.channels`  
- 触发：`notify.enabled` 或 CLI `--notify`  
- 长文截断；完整内容仍以本地文件为准  

## 6. 调度

- `scripts/run_scheduler.py`：APScheduler  
- `scheduler.morning_hour/minute`、`hour/minute`（收盘）  
- 时区默认 `Asia/Shanghai`，`mon-fri`  

## 7. 配置关键项

```yaml
# settings.yaml 摘要
data.skip_heavy_endpoints   # 弱网 true
llm.provider / model / base_url
scheduler.*
notify.enabled / channels[]
publisher.auto_publish      # 必须 false
```

## 8. 依赖（核心）

`akshare`、`pandas`、`pyyaml`、`feedparser`、`requests`、`fastapi`、`uvicorn`、`matplotlib`、`apscheduler`、`chinese-calendar` 等，见 `requirements.txt`。
