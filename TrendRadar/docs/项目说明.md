## 5. 关键配置

### 5.1 环境变量 `docker/.env`

```bash
AI_API_KEY=sk-你的DeepSeek密钥
AI_MODEL=deepseek/deepseek-v4-flash
DINGTALK_WEBHOOK_URL=https://oapi.dingtalk.com/robot/send?access_token=你的token
CRON_SCHEDULE=*/30 * * * *
RUN_MODE=cron
IMMEDIATE_RUN=true
TZ=Asia/Shanghai
```

- 模型：`deepseek/deepseek-v4-flash`
- 钉钉安全设置推荐：自定义关键词 `热点`

### 5.2 报告精简 `config/config.yaml`

```yaml
report:
  mode: "incremental"          # 只推新增
  max_news_per_keyword: 5      # 每组最多 5 条
```

### 5.3 关键词 `config/frequency_words.txt`

科技 / AI / 大模型 / 产品 方向，含：

- `[GLOBAL_FILTER]` 排除广告招聘等
- 大模型、主流模型、AI 公司
- 国内/海外科技公司
- 产品发布（`+发布` 等必须词）
- 软件、芯片算力、机器人
- 各组用 `@N` 限制条数

语法：`普通词` / `+必须词` / `!排除` / `@条数` / `[组名]`
